# Mapping Tutorial

### This tutorial will show you how to view T-BAS geoJSON file.

You can view the geoJSON file with the free [QGIS](https://qgis.org/download/) software.  

Once you have installed the software and downloaded the T-BAS geoJSON, then also get the [world&nbsp;boundaries](/tbas2_4/data/maps/world-administrative-boundaries.geojson) geoJSON. 

Open QGIS and to to Layer -> Add Layer -> Add Vectory Layer and select the file.
